# Shadowverse: Worlds Beyond マリガン練習

GitHub Pagesで公開できる、HTML/CSS/JavaScriptのみの静的Webアプリです。ビルドツールやサーバーは不要です。

## 使い方

1. `index.html` をブラウザで開くか、GitHub Pagesで公開します。
2. 「デッキ・設定」からカード名と枚数を入力します。
3. 合計40枚になったら「デッキを保存」を押します。
4. 「初期手札を引く」で4枚を抽選します。
5. 選択交換の場合はカードをクリックして交換対象を選び、「選択したカードを交換」を押します。
6. 全交換の場合は「4枚すべてを交換」を押します。
7. 交換後は「次の初期手札へ」で新しい練習を始めます。

### まとめて入力

入力欄に1行ずつ `カード名,枚数` の形式で入力し、「入力内容を反映」を押します。

```text
連筆の怪異,3
大遊戯世界,3
寸裂の盗人,3
```

タブ区切り、全角カンマも利用できます。反映後、合計40枚であることを確認して保存してください。

## 抽選ルール

- デッキの各枚数を物理的な1枚ずつに展開してシャッフルします。同名カードは複数枚同時に引けます。
- 初期手札は40枚から4枚を重複なしで引きます。
- マリガンでは、初期手札の4枚をデッキに戻さず、残り36枚から交換枚数分を引きます。
- 選択交換・全交換はいずれも1回だけです。
- 次の練習では40枚すべてから新しい4枚を引きます。

## 保存データ

デッキ1つと対戦相手デッキ名リストを、ブラウザの `localStorage` に保存します。保存データは同じブラウザ・同じ端末内でのみ利用できます。ブラウザのサイトデータを削除すると消去されます。

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html`、`css/`、`js/` をリポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定して保存します。
5. 数分後に表示されるPagesのURLへアクセスします。

## 補足

- デッキ内容は手動入力方式です。ゲーム内コードやDeck Portal URLからの自動取得は行いません。
- カード画像や外部APIは使用していません。
- Google Fontsを読み込めない環境では、端末標準フォントにフォールバックします。
